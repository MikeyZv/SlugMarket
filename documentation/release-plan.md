**SlugMarket**  
An exclusive marketplace for UCSC students. 

**MVP:**

- create and login into accounts  
- post listings  
- browse/search items  
- contact sellers

**Sprint 1: Core setup (user interfaces and list creation)**

- As a user, I want a browsable homepage so that I can discover available listings quickly. (8)  
- As a user, I want to fill out and submit a listing form so that I can post an item for sale. (8)  
- As a user, I want a login page so that I can log into my account or create an account. (5)  
- As a user, I want a profile page so that I can appeal to others. (5)  
- As a user, I want a navigation bar with links to other pages so that I can move between core sections of the app. (3)


**Sprint 2: Listing system and navigation**

- As a user, I want to view listing details so that I can decide whether to buy an item. (2)  
- As a user, I want to search listings by keyword so that I can quickly find items I'm looking for. (3)  
- As a user, I want to filter listings so that I can narrow results by price or category. (5)  
- As a user, I want my own listings to display on my profile so that I can track what I currently have for sale. (3)  
- As a user, I want to bookmark listings so that I can keep track of the items I’m interested in. (5)  
- As a user, I want to visit other users' profiles so that I can learn about sellers before buying from them and also see what other things they could be selling. (5)

**Sprint 3: Interaction**

- As a user, I want a messaging page so that I can keep track of my messages. (8)  
- As a user, I want to edit/delete my listings so that I can keep my listings accurate or remove sold items. (5)  
- As a user, I want to mark a listing as sold so that buyers know it's no longer available. (2)  
- As a user, I want to view my purchase history so that I can keep track of what I've bought. (3)  
- As a seller, I want to mark a listing as pending so that other buyers know the item is likely sold while waiting for the confirmed buyer. (3)  
- As a user, I want to be able to upload a profile picture so that others can see what I look like. (3)  
- As a buyer, I want an offering button and system so that I can easily make an offer that shows up rather than possibly going unseen by the seller. (3)  
- As a user, I want to see the count of other users interested in my listing so that I can better manage offering or editing listings. (1)

**Sprint 4: Customization**

- As a user I want to review or rate sellers and buyers so that I can help other users make informed decisions. (3)  
- As a user, I want my ratings/reviews to display on my profile so other users can determine if I’m trustworthy. (3)  
- As a user, I want to see the total amount of items sold on a seller’s profile page to help understand their reputation as a good or experienced seller. (1)  
- As a user, I want to add a bio to my profile page so that other users can learn about me before transacting. (1)  
- As a user, I want to report a listing or user so that I can flag suspicious or inappropriate content. (2)  
- As a user, I want to report and block a chat so that I can stay clear of inappropriate or rude behavior. (3)  
- As a user, I want to share a listing I saw to other people so that I can either get more opinions on the product or provide recommendations to others. (1)  
- As a user, I want an inbox so that I can be notified of agreements being made or a person interested in my item, etc. (5)
